# Gym AI Voice Receptionist & Front-Desk Kiosk

AI Voice Receptionist & Front-Desk Kiosk for Gyms powered by Google Gemini.

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment Variables
Copy `.env.example` to `.env` and add your Gemini API Key:
```bash
cp .env.example .env
```
Or configure the Gemini API key directly from the Dashboard UI after starting the server.

### 3. Run in Development Mode
```bash
npm run dev
```

### 4. Build & Run in Production
```bash
npm run build
npm start
```

The server runs by default on `http://localhost:4500`.
