# Reach AI Voice — Multi-Workflow Outbound Verification Dashboard (Frontend UI)

Frontend UI for **Reach AI Voice**, an Outbound-Only AI Voice Verification Dashboard supporting multi-client workflows (**TATA Leads Enquiry Verification**, **Healing Earth Service Verification**, and custom workflows).

---

## Project Structure

```text
Voice-agent-/
├── frontend/                  # Frontend UI (HTML5, CSS3, Vanilla JS)
│   ├── index.html             # Reach AI Voice Outbound Dashboard UI
│   ├── style.css              # Dashboard Stylesheet
│   └── app.js                 # Frontend logic, CSV parser, NLU intent classifier & local state
│
├── CLAUDE.md                  # Frontend UI guide for Claude Code
└── README.md                  # Documentation
```

---

## How to Run

Open `frontend/index.html` directly in Google Chrome (or use the VS Code **Live Server** extension). All 5 components, sample data, CSV upload/export, and live outbound call simulations work immediately out of the box.
